# PSX Studio

Éditeur de jeux 3D pour PlayStation 1, philosophie Unity, 100 % open source (MIT).

- `runtime/`  — moteur console (C, PSn00bSDK) — Phase 0 : `hello-triangle/`
- `pipeline/` — outils d'assets et de build (Rust) — à partir de la Phase 1
- `editor/`   — éditeur desktop (Tauri + React + TypeScript) — à partir de la Phase 4
- `docs/`     — doc projet (`psx-studio-doc-projet.md`) et guides de phase

Démarrage : voir `docs/PHASE0-GUIDE.md`.
